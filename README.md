# # GitHub CLI Tracker

A simple and elegant command-line tool written in Python to fetch and display GitHub user profile metrics instantly.

Instead of opening a browser, this tool uses the official GitHub API to track important metrics right from your terminal screen.

## Features
* **Real-time API Fetching**: Connects directly with GitHub to provide live profile details.
* **Formatted Console Output**: Colored outputs using `colorama` for clean visualization.
* **Error Handling**: Handles invalid usernames and internet connectivity exceptions automatically.

## Installation & Setup

1. **Clone this repository:**
   ```bash
   git clone https://github.com
   cd github-cli-tracker
   ```

2. **Install the required dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the tracker script:**
   ```bash
   python github_tracker.py
   ```
